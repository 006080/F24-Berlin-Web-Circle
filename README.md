# 🏡 Airbnb Clone – Final Full-Stack Project

## 📌 Overview

This project is a clone of the Airbnb (ARNBB) platform built collaboratively by our team as the final project at **ReDi School**, during the **Web Circle course**. While our main focus was on **frontend development**, we also integrated essential **backend features** to make it dynamically functional.

> 🛠 **Frontend:** Built using **React + Vite**  
> 🔧 **Backend:** Developed with **Node.js & Express.js**  
> 🧪 **Testing:** Implemented with **Jest**  
> 🗄 **Database:** Connected via **PostgreSQL** using **Prisma ORM**  
> ☁️ **Deployment:** Frontend hosted on **Netlify**

## 🔑 Key Features

- 🧭 **Home Page** – Browse available stays
- 🔍 **Search & Filter** – Filter by location, date, guests
- 🏘 **Property Details** – View detailed info, images, and amenities
- 📝 **Booking UI** – Simulated booking experience
- 👤 **User Authentication UI**
- 📦 **Dynamic Data** – Pulled from the `services/` folder
- 📄 **Google Maps Integration**
- ⚙️ **Backend Simulations** – With Express.js APIs
